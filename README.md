# urent-qr-generator
к сожалению маленький IT отдел местной северодвинской компании юрент не смог реализовать удобное создание qr кодов на самокаты и это пришлось вайбкодить бедолаге технику (повысьте мне зарплату)

руководство по использованию для самых маленьких:

скачайте последний релиз в формате .zip здесь: https://github.com/ejqrmj32kfmsd/urent-qr-generator/releases
распакуйте содержимое архива в любую удобную для вас папку
запустите файл .exe
введите номера самокатов в формате xxx-xxx или xxxxxx
импортируйте готовый шаблон для распечатки любым удобным для вас способом
