# urent-qr-generator
к сожалению маленький IT отдел местной нижнегородской компании юрент не смог реализовать удобное создание qr кодов на самокаты и это пришлось вайбкодить бедолаге технику (повысьте мне зарплату)

руководство по использованию для самых маленьких:

1) скачайте последний релиз в формате .zip здесь: https://github.com/ejqrmj32kfmsd/urent-qr-generator/releases
2) распакуйте содержимое архива в любую удобную для вас папку
3) запустите файл .exe
4) введите номера самокатов в формате xxx-xxx или xxxxxx
5) импортируйте готовый шаблон для распечатки любым удобным для вас способом.
